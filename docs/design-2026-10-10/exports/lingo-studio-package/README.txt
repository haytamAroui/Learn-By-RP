LINGO UX EXPERIENCE STUDIO — COMPLETE PACKAGE

1. Extract the entire ZIP to a folder.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Use the screen library or screen board to explore all 142 screens.
4. Use the palette bar for Warm / Warm Midnight and the five color palettes.

Keep the assets folder beside index.html. Fonts, artwork, styling and scripts
are included. The package needs no installation or internet connection.

This is an interactive design prototype. Accounts, subscriptions, progress and
learning content are examples. Recording and playback are visual simulations.
